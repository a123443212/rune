# RUNE v0.10 Specification — single source of truth

This directory is canonical. When C++, Rust, and Python disagree,
this directory wins. Code mirrors it; prose elsewhere does not
override it.

Layering:

```text
spec/            Layer 1 semantics (this directory)
C++/Rust kernels Layer 2 implementations of exactly this
applications     Layer 3 consumers (engine, CLI, research)
```

Contents:

- `features/` — feature IDs and extraction semantics
- `architecture/` — mixer, head, routing, config table, `architecture-spec.json` (generated artifact, checked in)
- `model-format/` — `.rune` framing, header fields, payload order, checksum, versioning
- `quantization/` — quant/dequant rules per precision
- `tensors/` — dims, dtypes, layout, row-major order, alignment notes
- `test-vectors/` — golden fixtures consumed by all three languages (versioned)
- `numerical-contract.md` — per-operation exactness, rounding, saturation, accumulation width
- `VERSIONS.md` — independent version numbers per layer

Canonical artifacts:

- `spec/architecture/architecture-spec.json` is generated from
  `training/models/` canonical config and checked in. C++ and Rust
  must not hand-copy dims.
- `spec/test-vectors/v10/*.json` are generated by
  `tools/golden/gen_vectors.py` and are the only cross-language
  oracle. Unit tests inside one language are supplementary.

Endianness: little-endian everywhere on the wire. In-memory layout
is row-major. Floats are IEEE-754 binary32. Integers are two's
complement. Serialization order is fixed and checked by hash.
