# RUNE v0.1 Experiments

## Hypotheses

- H1: Grouped tokens + MLP match or beat the SFNN reference at similar cost.
- H2: Non-softmax attention over semantic tokens improves ranking accuracy and
  playing strength over the grouped MLP at comparable inference cost.
- H3: The learned 8x8 geometric bias adds a measurable gain over attention
  without bias.
- H4: Sibling ranking loss improves ordering metrics without hurting absolute
  value/WDL.
- H5: Filtered + disagreement sampling improves data efficiency vs random, but
  only after clean filtering (never disagreement-only).

No conclusion about attention is drawn before benchmarks exist. Every claim
below requires the named ablation.

## Baselines and models

- A: `RUNE-SFNN` (`configs/v01/baseline/sfnn.json`)
- B: `RUNE-MLP` (`configs/v01/baseline/grouped_mlp.json`)
- C: `RUNE-ATTN` (`configs/v01/rune_v01/rune_attn.json`)
- D: `RUNE-ATTN-GAB` (`configs/v01/rune_v01/rune_attn_gab.json`)

## Ablation matrix

| Axis | Variants | Config |
|------|----------|--------|
| Architecture | SFNN vs MLP vs ATTN vs ATTN+GAB | `configs/v01/baseline/*`, `configs/v01/rune_v01/rune_attn*.json` |
| Loss | Value/WDL vs +Ranking | `configs/v01/rune_v01/ablation_ranking.json` sets `lambda_rank: 0.1` |
| Data | Random vs Filtered vs Filtered+Disagreement | `sampling` field; `ablation_sampling.json` uses `disagreement` |

Change one axis at a time. Never mix an architecture change with a loss or
data change in the same comparison.

## Metrics

Per milestone record: training positions, validation loss, WDL accuracy,
ranking accuracy, parameter count, model size, training compute, eval latency,
NPS, memory, match score/Elo. The learning-curve CSV stores the subset
computable without a cluster; match Elo is appended by `tools/match`.

## Learning curve

Milestones: 100M, 250M, 500M, 1B positions. `LearningCurve` trains one epoch
per milestone over a milestone-sized pool (`pool_ratio: 1.0` default), so
budget and data scale together. `milestone_budgets` / `max_positions_cap`
exist only for smoke tests. Primary plots: strength vs training data and
strength vs inference cost.

## Interpretation rules

- Attention wins only if C beats B at matched inference cost with fixed
  loss and data.
- GAB wins only if D beats C with everything else fixed.
- Ranking loss wins only if ordering metrics improve without value/WDL
  regression on the same architecture and data.
- Disagreement sampling wins only on top of the clean pipeline, with the
  random mixture fraction reported.
- Match results require equal time/nodes, both colors, and a fixed opening
  set; greedy-play results are directional, not conclusive.
