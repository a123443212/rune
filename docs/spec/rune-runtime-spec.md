# RUNE runtime spec (v0.10, Layer 1 summary)

Canonical source is `spec/`. This file is a readable index.

- Features: `spec/features/grouped-hkav2.md`, version
  `grouped_hkav2_fullthreats_v01`. Sorted unique (group,index).
- Tensors: `spec/tensors/layout.md`. Row-major, token buffer
  T*D, embedding rows vocab*width, int32 acc for quant paths.
- Quantization: `spec/quantization/rules.md`. Symmetric
  per-group, half-away-from-zero, saturating, LE storage.
- Architecture: `spec/architecture/runtime.md` +
  `architecture-spec.json`. Mixer order QKV → QKᵀ+gab+bias →
  gate → S@V → residual; head flatten → clip → clip → tanh +
  linear WDL; routing `>=` with NaN→refine.
- Model format: `spec/model-format/rune10.md`. Magic RUNE,
  u32 LE header len, JSON header, payload in tensor order,
  FNV-1a64 hash over payload, format 1+2 accepted, 2 written.
- Numerical contract: `spec/numerical-contract.md`. Exact vs
  tolerant per operation, no global epsilon.
- Versions: `spec/VERSIONS.md`. Runtime spec, format, arch,
  data schema versioned independently.
- Vectors: `spec/test-vectors/v10/` + `models/`. Generated by
  `tools/golden/`, consumed by all three languages.
